# 🍀 Sortudo Analyzer — Análise Estatística de Loterias Brasileiras

Sistema inteligente de análise estatística de loterias brasileiras (Mega-Sena, Lotofácil, Quina e Dia de Sorte).

## 🚀 Funcionalidades
- **4 Loterias Suportadas**: Mega-Sena, Lotofácil, Quina e Dia de Sorte.
- **7 Engines Estatísticos**: Frequência, Atraso, Equilíbrio Par/Ímpar, Zona Ideal de Soma, Distribuição por Quadrantes, Repetições e Composição Histórica.
- **Gerador de 12 Palpites Inteligentes**: 4 estratégias (Quente, Equilibrada, Fibonacci e Composição Histórica) × 3 jogos.
- **Salvar & Conferir Palpites**: Salva seus palpites no `localStorage` e confere automaticamente acertos e premiações quando novos resultados saem.
- **Ranking de Assertividade**: Mostra qual estratégia obteve a maior taxa de acertos nos palpites salvos.
- **API Real + Fallback Local**: Consome dados da Caixa Econômica Federal via API com suporte a fallback offline.

## 🛠️ Tecnologias
- HTML5 / CSS3 Vanilla (Design System Dark Navy + Gold + Glassmorphism)
- JavaScript ES6+ (Módulos nativos)
- Chart.js (Gráficos interativos)
- Node.js (Servidor HTTP estático nativo)

## 🏃 Como Executar
```bash
# Iniciar o servidor local na porta 3030
node server.js
```
Acesse em: `http://localhost:3030`

---
*Aviso: Este projeto é voltado para análise estatística e entretenimento. Loterias são eventos aleatórios e nenhum sistema garante vitórias. Jogue com responsabilidade.*
